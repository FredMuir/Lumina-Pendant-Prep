# 项目目标与 Windows 首发验收

## 总目标

提供中文 Windows 桌面软件，将真实照片处理成可导入 Lumina-Layers 的透明 PNG，用于制作多层叠色照片牌和挂坠。用户能按实际成品尺寸预览并减少难以打印的零碎色块，同时自行检查和保护重要细节。软件不替代 Lumina 的材料配方、建模、切片或打印校准。

先完成 Windows 功能与下列验收，再启动 macOS。喷嘴直径仅提供 **0.2、0.4、0.6 mm** 三个选项。照片效果、格式和打印验证使用真实拍摄的照片，不使用 AI 生成或程序绘制的照片；几何算子单元测试可以使用简单图形。

## 色块净化的具体目标

1. 图像方向和色彩处理后，以最终裁切区域宽度和目标物理宽度计算像素密度；透明像素不参与颜色合并。
2. 提供真正的“关闭净化”，使同一裁切、尺寸与孔设置下能够比较处理前后；关闭时不执行颜色量化或小色块合并。
3. 在启用净化时使用无抖动量化和局部连通区域合并。依据感知色差、公共边界和边缘信息选择目标；同色标签在远处出现时，不因局部合并而自动改变远处区域。
4. 为细线、眼睛、毛发、文字和轮廓提供可见警示与手动保护；支持撤销。不会承诺自动识别并保留所有语义细节。
5. 分别显示量化和区域合并带来的变化；报告较小连通区域数和变更区域，指标必须注明计算尺度。先建立实拍和打印基线，再决定可衡量的改善阈值。

## 优先顺序与完成条件

1. **基线和样本**：建立可追溯实拍样本清单，实现关闭净化的基准流程，记录现有输出与已知缺陷。
2. **准确性**：完成物理尺度换算、局部合并、透明边界、保护区域和导出一致性；用实拍照片覆盖格式及主体细节。
3. **可用性与兼容性**：完善中文 GUI、项目恢复、错误提示及大图响应；在干净 Windows 环境测试分发包和 HEIC 依赖，核对第三方分发许可。
4. **下游与实物**：固定 Lumina、材料和切片设置，完成照片对照及配对打印，保存设置、照片和结果；异常或失败样本须保留并复测。
5. **Windows 验收后**：基于通过验收的核心功能开始 macOS 移植、打包及平台测试。

每个目标只有在功能实现、相应实拍测试、缺陷修复和可复查证据齐备后才能标为通过。实拍样本、完整下游验证、配对打印和干净 Windows 测试目前均未完成；现有原型及自动化测试不能代替这些验收。

## 本阶段不纳入的功能

首发不要求自动抠图、AI 照片生成、3MF 生成、材料配方求解、切片或自动打印；批处理、英文界面和云端服务留待后续评估。项目默认本地处理，私人照片不自动上传。

详细测试样本、指标定义和实物记录要求见 [实拍照片验证方案](PHOTO_VALIDATION.md)；实现思路及复用项目见 [产品与技术计划](PLAN.md)。
