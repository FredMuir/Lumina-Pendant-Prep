# 产品与技术计划

## 问题

多层叠色 FDM 图像中，孤立小色岛、狭窄线条和噪声边界会造成难以稳定打印的细节。现有工作区的挂坠脚本已经尝试颜色量化和小连通域合并，但目前缺少统一的桌面交互、对物理尺寸的完整约束以及所需的透明裁切与格式兼容体验。

## 用户与主要场景

用户使用照片制作层叠色打印的照片牌或挂坠。希望在送入 Lumina-Layers 前检查并简化图像，设置挂坠外形和挂绳孔，然后得到可直接导入的透明 PNG。

## 产品原则

1. **先预览再导出**：所有自动合并均可视化，不静默覆盖原图。
2. **打印尺寸驱动**：特征宽度、孔径和圆角均以毫米表达，并根据目标导出尺寸换算像素。
3. **保留颜色关系**：用感知色彩距离和邻接关系合并；不要用抖动来掩盖量化误差，因为它会制造更多碎点。
4. **轮廓与孔使用 alpha**：背景和孔内是真正透明像素；预览棋盘格与导出 PNG 保持一致。
5. **把照片美化与打印净化分开**：不默认锐化、磨皮或改变主体颜色；Lumina 保持材料色彩匹配职责。
6. **跨平台可预测**：Windows 和 macOS 提供一致的核心交互和参数；平台差异集中在安装包、文件对话框和系统图像解码依赖。

## 功能规格（MVP）

### A. 输入与图像方向

- 文件选择和拖放；输入 JPG/JPEG、PNG、WebP、BMP、TIFF、HEIC/HEIF。
- AVIF 作为技术验证通过后加入的扩展格式。
- 读取 EXIF orientation 后再显示和处理；保留正确的 ICC 色彩配置，至少在解码和转换时明确色彩假设。
- 多图 HEIF 首版只读主图，并明确告知用户；损坏文件显示可操作错误信息。

### B. 色块净化

- 参数：成品宽度 mm、最小线宽 mm、最小色岛面积 mm²、颜色相似阈值、净化强度。
- 先把图像转换为无抖动的有限颜色标签，再做相邻区域聚合和小区域重标记。
- 颜色距离采用 Lab/ΔE 一类感知近似；合并目标综合颜色差、共享边界长度、区域面积和边缘显著性。
- 同时检测细线宽度/局部距离变换，防止仅用像素面积阈值误删细长形状。
- 保持 alpha 边界，不将透明区当成颜色；4/8 邻接关系需可验证并选定默认值。
- 预览至少包含：原图、净化结果、差异叠加/合并区域图层；提供强度滑杆、撤销/重做。
- 输出统计：调色板颜色数变化、合并区域数、最小保留特征估计值。

### C. 挂坠形状与结构裁切

- 几何模板：矩形、圆形、圆角矩形；可编辑多边形作为自定义外形。
- 在画布内平移、缩放、旋转裁切框；外部 alpha=0。
- 圆角半径、孔径按毫米输入；明确成品像素密度后转换。
- 挂绳孔由内部圆形蒙版切出透明 alpha；鼠标拖动孔位置，并显示边缘剩余材料宽度的估计值/提示。
- 避免孔遮挡重要内容由用户负责确认；首版不依赖不可靠的自动语义判断。
- 后续可研究自动主体轮廓提取，但和几何裁切分开设计，作为独立功能开关。

### D. 导出与项目

- PNG 为必需导出格式，RGBA、真透明孔和背景。
- 可设置输出像素尺寸或 DPI；写入可用的 PNG 物理尺寸元数据，并同时在 JSON 项目记录目标毫米尺寸，避免仅靠 DPI 推断尺寸。
- 导出检查：图片尺寸、alpha 通道、透明角点/孔、潜在过细特征警告。
- 保存处理参数 JSON 与源路径引用；不把用户照片自动上传或写入公开仓库。

## 图形界面布局

- 顶栏：打开/拖入、保存项目、导出 PNG、撤销/重做。
- 左侧：输入图层、打印尺寸、喷嘴、色块净化参数、形状/孔控制。
- 中央：带透明棋盘格的画布，可拖拽轮廓和孔位置。
- 右侧或底部：原图/结果并排或滑动分割对比；可切换合并区域、轮廓边界和物理尺寸网格叠层。
- 关键参数旁显示简短的毫米与像素对应值；复杂参数提供保守默认与高级设置折叠区。
- 长图处理可取消；GUI 线程不直接运行图像算法，后台任务提供进度和取消状态。

## 技术架构草案

- `ui/`：PySide6 主窗口、画布交互、参数面板、对比预览。
- `io/`： Pillow 解码/导出、pillow-heif 注册、EXIF/ICC/异常处理。
- `core/`：纯函数图像处理；算法与 GUI 分离，便于离线验证。
- `project/`：版本化 JSON 设置模式和迁移。
- `packaging/`：Windows/macOS 构建配置、图标与安装说明。

建议依赖起点：Python、PySide6、Pillow、pillow-heif、NumPy、OpenCV。实际依赖和版本在技术验证后锁定；应避免同时引入多个功能重叠的图像处理栈。

## 公开项目复用评估

| 项目/库 | 可复用部分 | 本项目采用方式 |
|---|---|---|
| pillow-heif | HEIC/HEIF 接入 Pillow、主图解码 | 作为可选/基础依赖做 Windows 与 macOS 安装包验证 |
| Pillow | 格式读写、EXIF、alpha mask、PNG | 直接依赖 |
| OpenCV | connected components、形态学/距离变换 | 选取底层算子，构建面向打印的自有决策规则 |
| MultiClean | 小岛移除、无效区域填充思路 | 阅读算法，不照搬遥感默认值 |
| ImageLayerDecomposer | Lab、色聚类、交互预览案例 | 检查许可与代码成熟度；先参考思路，不复制实现 |
| Lumina-Layers | 下游颜色匹配和打印输出 | 通过 PNG 工作流互补，MVP 不改动 Lumina 本体 |
| 工作区已有 pendant scripts | 孔透明裁切、像素阈值、小色岛处理 | 作为行为参考；检查脚本细节后择优整合并保留出处/许可信息 |

任何代码复制前需确认其许可证允许当前项目的使用和再分发；依赖许可证写入第三方声明。参考链接不代表已验证兼容，也不构成代码复用许可。

## 里程碑与验收标准

### 0. 技术验证

- Windows 与 macOS 均启动 PySide6 窗口。
- 覆盖常见 JPEG/PNG/WebP/TIFF；由真实 HEIC 样本验证 EXIF 方向、颜色、alpha/多图限制和失败提示。
- 输出的 PNG 在 Pillow 与系统预览器中 alpha 正常。
- 记录 PyInstaller/Nuitka 对 HEIF codec 的打包与分发限制后选定方案。

### 1. 算法原型

- 给定目标尺寸后，mm 到像素阈值计算可预测。
- 合成用例涵盖小点、孤立噪声、细线、对角接触、脸部/文字边缘、透明边缘。
- 强度为零时不改变输入像素；小岛合并不能越过透明边界；算法不生成抖动噪声。
- 可在真实图片上对照打印结果评估边界简化。

### 2. MVP GUI

- 完成导入、实时/后台预览、参数、撤销/重做、轮廓裁切、圆角、透明孔及 PNG 导出。
- 所有几何参数可用毫米查看或编辑；显示像素换算。
- 用户可视觉确认输出透明区域和孔内透明状态。

### 3. 分发与打印验证

- Windows/macOS 可安装包及离线安装指南。
- 用至少两种照片风格、两种目标尺寸完成物理打印对照，记录喷嘴/材料/Lumina 配置。
- 默认参数仅在实物样例验证后确定；软件提示是估计值，不承诺某台打印机必然能打印某尺寸细节。

## 未决事项

- PySide6 6.12 将是 Qt 6 对 Windows 10 的最后一个支持版本；当前依赖上限暂锁在 6.12 系列，后续升级需重新确认 Windows 10 支持策略。
- 是否需要完整 ICC 色彩管理、CMYK 输入或仅将照片转换至 sRGB。
- 最小可打印特征宽度的初始默认值目前取喷嘴直径与用户设置的较大值；这是保守估计，需用用户打印样例校准。
- 是否在 MVP 纳入自定义多边形节点编辑，或先以几何模板满足最常见挂坠外形。
- 是否提供批处理和英文 UI（建议架构支持，首版界面先中文）。
- 仓库的代码许可证尚未确定；在确定前不应把项目描述成已授予第三方代码再分发权。

## 当前实现状态

- 已建立 Python 包结构和 PySide6 桌面窗口；提供照片导入/拖放、参数面板、透明棋盘格的双画布、后台预览、撤销/重做与 JSON 项目保存/读取。
- 已实现 EXIF 方向处理、常见栅格格式及 pillow-heif 接入、ICC 到 sRGB 的尽力转换。
- 已实现无抖动调色、相邻 Lab 近似色合并、小连通域按物理尺寸合并，以及狭窄区域提示。
- 已实现矩形/圆形/圆角矩形/多边形 alpha 裁切、透明孔、PNG 导出和 DPI 元数据。
- 项目按用户新确定的顺序聚焦 Windows 首发。GitHub Actions 只构建 Windows x64；macOS 移植与打包须等 Windows 功能完整且验证通过后再开始。
- Windows 安装包签名和实物打印仍待验证。
- 实现是首个原型；默认参数和照片保真需结合真实打印反馈调整。
