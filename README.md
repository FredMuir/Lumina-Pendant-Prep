# Lumina Pendant Prep

面向 Lumina-Layers 等多层叠色 FDM 工作流的桌面图像预处理工具。当前阶段专注完成 Windows 版；功能与 Windows 体验验证通过后，再开始 macOS 移植与打包。

## 目标

将常见照片格式（包括 HEIC/HEIF）转换为容易检查、方便继续导入 Lumina 的 PNG。用户可以预览并控制小色块合并，也可以为挂坠设置裁切轮廓、圆角和透明挂绳孔。

## 当前原型

- 图形界面支持打开/拖放照片、参数调节、后台预览、撤销/重做和保存/重开 `.lpproj` 项目。
- 打开照片不会自动净化；设置完成后勾选“开始处理并生成预览”。默认输出长边不超过 2400 像素，也可选择 4096 或原始分辨率。
- 左侧参数面板可滚动，窗口高度较小时仍可访问挂坠设置和处理状态。
- 前后预览可同步选择适合窗口、2 倍或 4 倍，放大后滚动查看细节；缩放不影响导出像素或物理尺寸。
- 修改参数时会取消过时的后台预览并处理最新设置；部分图像解码和底层运算需到下一个检查点才能中止。
- 输入 JPEG、PNG、WebP、BMP、TIFF、HEIC/HEIF 和 AVIF；读取 EXIF 方向，尝试转换嵌入的 ICC 配置至 sRGB。无 ICC 或转换失败时按 sRGB 处理并在图像信息栏提示；导出 PNG 写入 sRGB 配置。
- 多图 HEIF 读取容器主图，多页 TIFF 读取第一页；文件包含多张图片时，信息栏会显示实际加载的帧。
- 无抖动调色、相邻近似色合并、小连通色岛合并，并高亮净化影响区域；喷嘴尺寸作为最小特征阈值下限，同时报告可能过窄的连通区域。
- “温和预设（试用）”将颜色上限设为 96、相近色阈值设为 2、最小特征宽度设为当前喷嘴直径；可撤销并继续调整。该预设尚未通过实物打印校准。
- 可在原图上框选多个保护区域，使区域内原色不参与量化和色块合并；保护区域支持撤销并随项目保存。
- 通过拖动裁切框、选择矩形/圆形/圆角矩形或点击绘制自定义多边形创建挂坠轮廓。
- 可设置毫米圆角、挂绳孔直径和孔位置；画布外区域和孔内均为 PNG alpha 透明像素。
- 可选孔径补偿默认 0 mm；设置后会加到 PNG 的裁切孔径，建议依据实际切片或打印样品测量后调整。
- 外边框和孔内边框可分别启用、设置宽度和颜色。外边框向轮廓外扩展，不遮挡照片；孔边框位于透明孔内，会缩小透明开口。
- 启用挂绳孔时，如果孔附近无法留出估计的材料边距，预览不会裁孔且导出会被阻止；可调整孔或明确关闭挂绳孔。
- 导出 RGBA PNG，PNG DPI 按目标物理宽度写入；导出和保存项目时拒绝覆盖当前原照片。

算法输出是打印可行性估计。真实照片和材料组合仍应先打印小样确认；量化和小色块合并可能改变细线，请检查预览并按需框选保护区域。

狭窄区域提示按连通色块的整体宽度估计，能覆盖面积较大的长细线；大色块上局部细小的延伸仍可能漏报，不能替代切片和实物检查。

## Windows 开发环境

普通用户可在 [GitHub Releases](https://github.com/FredMuir/Lumina-Pendant-Prep/releases) 下载 Windows x64 安装程序。安装后从开始菜单打开，安装时可选择创建桌面快捷方式；新版安装程序可覆盖此前的安装版。软件不自动联网更新，需自行下载并运行新版本。发布包未签名，Windows 可能显示发行者未知提示。该试用版尚未完成干净系统及实物打印验收。

以下为源码开发者说明。安装版和开发机本地构建版本使用不同目录，互不自动切换或删除。

双击桌面的“Lumina Pendant Prep”快捷方式，或项目内的 `启动 Lumina Pendant Prep.cmd`，启动本机已安装的版本。版本安装在本机用户目录，由版本指针选择当前版本；以后更新源码后可运行 `scripts/build_windows.ps1` 构建、验证并替换本地版本。启动器不自动下载网络更新。

如果开发构建由 Windows 上的 Codex 桌面应用运行，Windows 可能将其重定向到 Codex 的本地缓存；项目启动器在普通目录没有版本时会检查该缓存。普通安装版独立于此机制。

需要 Python 3.10 或更新版本。当前首发开发与验证环境为 Windows：

```bash
python -m venv .venv
```

Windows PowerShell：

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python run_app.py
```

GitHub Actions 当前只在 Windows x64 runner 上构建 Windows 版打包产物，并用实拍 JPEG 执行打包后离屏启动和透明 PNG 导出检查。macOS 目标暂缓，待 Windows 功能齐全并通过验证后再启动。

本地生成 Windows 文件夹版（从项目根目录执行）：

```powershell
python -m pip install -e . pyinstaller
python -m PyInstaller --clean --noconfirm LuminaPendantPrep.spec
```

程序位于 `dist/LuminaPendantPrep/LuminaPendantPrep.exe`；运行或复制时需要保留整个 `LuminaPendantPrep` 文件夹。

运行核心和图形界面验证：

```powershell
python -m unittest discover -s tests -v
```

## 操作

1. 打开照片，设置目标宽度、喷嘴、最小特征宽度和净化参数；勾选“开始处理并生成预览”。
2. 在左侧图像拖动鼠标定义裁切框；选择“点击设置孔位置”后在图像上定位孔。
3. 选择轮廓类型。绘制多边形时左键添加节点、右键结束；重新开始时按“重置裁切框”。
4. 需要保护眼睛、文字等细节时，选择“拖动添加保护区域”并在原图上框选；可多次添加，使用撤销或“清除保护区域”修改。框内保留原色，但裁切和挂绳孔仍会生效，框内细节不保证可打印。
5. 勾选预览区“标记已简化区域”，选择全部变化、颜色量化或区域合并，检查受影响的像素。标记只用于预览，不写入 PNG；状态栏比例以孔切除前、除保护区域外的轮廓内可见像素为分母，两类变化可能重叠。
6. 保存项目以保留原照片路径和参数；导出透明 PNG 后导入 Lumina-Layers。

## 技术路线

- Python + PySide6：一个桌面应用代码库，使用 Qt 提供 Windows/macOS 图形界面。
- Pillow：常见格式解码、EXIF 方向、RGBA/PNG、裁切、遮罩与圆角。
- pillow-heif：HEIC/HEIF 解码并注册为 Pillow 插件；对应用安装包做真实照片兼容验证。
- NumPy + OpenCV：颜色标签、连通域、小色岛筛选、距离/边缘约束等计算。通过独立处理模块隔离算法，GUI 不直接操作像素循环。
- PyInstaller：先验证 Windows 构建与分发；macOS 打包在 Windows 验收完成后再启动。本地依赖、HEIF codec 和安装包大小需在技术验证阶段确认。

先检查 Windows 打包后的 HEIC 解码表现、色彩配置、运行速度和分发许可；macOS 和 Apple Silicon 的验证放在后续阶段。

## 交互流程草案

1. 打开或拖入照片，显示原图及文件信息；自动应用 EXIF 旋转。
2. 设置目标宽度、喷嘴直径（0.2、0.4 或 0.6 mm）与最小特征宽度；确认设置后开启处理并生成预览。
3. 用并排/叠加视图比较原图和结果；显示色岛合并图层，允许调参数并撤销。
4. 选择挂坠轮廓并编辑边界；设置圆角和挂绳孔的直径、位置。
5. 检查 alpha 透明区域及打印尺寸，导出 PNG 和可选项目 JSON。

默认操作均非破坏性。用户确认参数后再输出文件；不自动替用户提交切片或打印。

## 实施阶段

1. **技术验证**：Windows PySide6 窗口、HEIC/HEIF 解码、RGBA PNG 导出与安装包依赖验证。
2. **图像核心**：方向/色彩处理、毫米到像素换算、基于感知色差和连通域的小色块合并；使用实拍照片验证照片效果，几何边界可用程序构造的图形进行单元测试。
3. **桌面 MVP**：导入、对比预览、参数控制、撤销/重做、圆/圆角矩形/多边形裁切、透明孔、PNG 导出。
4. **可用性与分发**：项目设置保存、边缘情况提示、Windows 分发包与用户文档；Windows 验收后再做 macOS。
5. **打印验证迭代**：用不同尺寸、喷嘴、材料配色的实物打印检查边界；据此调整默认阈值。

## 开源复用与参考

采用成熟库承担通用编解码、图形界面与像素运算；自研部分聚焦“按实体打印尺寸治理色块”及挂坠流程的交互。

- [Lumina-Layers](https://github.com/lumina-layer-studio/Lumina-Layers)：目标下游；已有校色、局部颜色处理与 3MF 导出，本项目输出可检查的 PNG，不重复实现打印配方与切片导出。
- [pillow-heif](https://github.com/bigcat88/pillow_heif)：Pillow 的 HEIF/HEIC 支持；优先验证其打包及 codec 依赖。
- [Pillow](https://github.com/python-pillow/Pillow)：格式读写、EXIF 方向、alpha 通道与遮罩基础操作。
- [OpenCV](https://github.com/opencv/opencv)：连通域标记、形态学操作等通用图像算子；只选取适合打印边界且容易回退的处理。
- [MultiClean](https://github.com/DPIRD-DMA/MultiClean)：多类别栅格的小岛移除与边缘清理思路参考。其遥感场景不直接复用为默认参数。
- [ImageLayerDecomposer](https://github.com/CactusQuill/ImageLayerDecomposer)：颜色聚类、LAB 感知色差、连通域与预览交互的案例参考；关注其许可后再决定是否复用代码。
- 工作区已有 `make-photo-stamp-archive` 脚本：挂绳孔透明裁切、圆角/边框相关处理和颜色孤岛简化可作为需求与算法基线；先检查并抽取通用规则，避免复制后形成两套实现。

复用第三方实现前需逐项核对代码许可证、依赖许可证、维护状态和分发义务。当前计划不复制上述仓库代码。

## 方案边界与待验证项

- “相似颜色”须按感知色差判断，而不是仅按 RGB 欧氏距离；但应提供可理解的强度设置。
- 面积阈值之外还需考虑细长特征宽度；同面积的圆点与细线对打印的可行性不同。
- 对人脸、文字和主体轮廓的保护策略需通过照片样例验证，不能承诺自动识别后绝不误伤。
- HEIC 容器可能包含多帧、HDR 或特殊色彩信息；首版明确支持范围和失败提示。
- “挂坠裁切”首版定义为用户可控的几何轮廓裁切；自动抠出照片主体可作为后续独立功能评估。
